NATUREX — MAIN WEBSITE (VISUAL REFINEMENT)
=========================================

START HERE
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Install/use the Live Server extension.
4. Right-click home.html and choose “Open with Live Server”.

SITE MAP
home.html          Main landing page
discover.html      Search and filter destination inspiration
destinations.html Destination collection
journeys.html      Saved-place and trip-planning entry point
guardian.html      Pre-trip preparation checklist
about.html         Project overview
login.html         Entry point to application sign-in
app.html           Original NatureX V18 application

SHARED DESIGN FILES
premium.css        Responsive public-page design system
premium.js         Navigation, local favourites, checklist, reveal effects
style.css          Styling layer for the original main application
manifest.webmanifest  Basic install metadata

WHAT WAS IMPROVED
- More structured home page with a split visual hero and clear action hierarchy.
- Consistent shared navigation and active-page indication.
- Refined spacing, typography, cards, responsive layouts and visual hierarchy.
- Mobile navigation closes after selection and supports Escape.
- Scroll progress and back-to-top control.
- Existing destination save and Guardian checklist behavior retained.

IMPORTANT LIMITATIONS
- Saved places and Guardian checklist are stored locally in the current browser.
- Cloud sync, live authentication, maps, weather, and database access depend on valid backend/API configuration in app.html.
- External fonts and remote image sources require an internet connection.
- This is a frontend/design integration, not a security audit or backend deployment.
- Check destination access, travel conditions, permits and local guidance before travel.
